# 서울 사고누적지점 분석

서울의 사고누적지점에서 발생한 사망·중상사고를 대상으로, 운전자가 지점별로 주의할 사고 유형을 확인할 수 있는 지도를 만든다.

[서울 사고 유형 지도 열기](https://agliotomato.github.io/BigData_Project/)

| 프로젝트 기록 | 내용 |
|---|---|
| [데이터 수집](docs/데이터_수집.md) | TMACS 조회 조건, 재현 명령, 원본 파일과 2025년 수집 검증 |
| [데이터 전처리](docs/데이터_전처리.md) | 2023~2025년 분석 자료, 원본 대조, 지점별·서울 전체 집계 기준 |

서울 25개 자치구의 327개 사고누적지점에서 2023~2025년에 발생한 사망·중상사고 4,564건을 분석한다. [분석용 CSV](data/processed/사고_분석용.csv)

## 노트북 실행 순서

시설 수와 사고유형 비중을 분석할 때는 01 → 02 → 03 순서로 실행한다. 사고유형 지도는 01의 결과만 있으면 04에서 그릴 수 있다. 노트북 파일명은 영어로, 셀 설명은 한국어로 작성한다.

이 프로젝트에서 검증한 Jupyter 커널 이름은 `Seoul Accident (Python 3.12)`이다. 커널 선택기에 이 이름이 없는 다른 컴퓨터에서는 NumPy, pandas, Matplotlib, IPython, Jinja2, openpyxl, scikit-learn이 설치된 Python 커널을 선택한다.

| 노트북 | 입력과 결과 |
|---|---|
| [01 · 사고 데이터 전처리](notebooks/01_prepare_crash_data.ipynb) | TMACS 사고상세와 지점목록을 대조하고, 사고 한 건당 한 행인 분석용 CSV를 저장한다. |
| [02 · 주변 시설 집계](notebooks/02_count_nearby_facilities.ipynb) | 시설 원본과 CCTV 운영·위치 자료를 정리하고 사고 지점별 반경 안의 수량을 센 뒤 사고 행에 연결한다. 기본 반경은 1,000 m다. |
| [03 · 사고유형 비중 비교](notebooks/03_compare_crash_type_shares.ipynb) | 1,000 m 통합 CSV에서 시설별로 지점을 세 구간으로 나누고, 구간별 사고 건수로 비중·히트맵·발표 표를 만든다. |
| [04 · 사고유형 지도](notebooks/04_map_crash_types.ipynb) | 01의 분석용 CSV에서 지점별 사고유형 비중을 계산하고 지도에 표시한다. |

## CCTV 집계 기준

[02번 노트북 3.3절](notebooks/02_count_nearby_facilities.ipynb)에서 25개 구 수록 여부, 좌표 누락, 주정차 지점 중복, 기존 단속 장비와의 거리·ID 대조 결과를 확인할 수 있다.

| 1 km 집계 열 | 한 단위가 뜻하는 것 |
|---|---|
| 주정차외_무인단속카메라_대수 | 기존 단속구분 1·2·99의 카메라 ID 한 개 |
| 불법주정차CCTV_지점수 | 서울시 또는 자치구가 운영하는 고정형 불법주정차 단속지점 한 곳 |
| 무인교통단속카메라_집계수 | 위 두 열의 합. 기존 ‘무인교통단속카메라_대수’ 열을 대체한다. |
| 교통관리센터CCTV_대수 | 서울도시고속도로 교통관리센터 운영목록에 있는 관제 ID 한 개. 단속 합계와 별도로 집계한다. |
| 전체CCTV_집계수 | 무인교통단속카메라_집계수 + 교통관리센터CCTV_대수. 불법주정차 단속지점, 주정차 외 무인단속 장비, 교통관제 장비를 합한 건수. |

주정차 자료는 2026-10-01 갱신본의 CSV를 UTF-8로 저장했다. 전용차로를 걸러내고 기존 자료의 주정차 행은 새 자료로 대체한다. [서울시 주정차·전용차로 단속 CCTV](https://data.seoul.go.kr/dataList/OA-20471/S/1/datasetView.do)

교통관제는 2026-07-29 운영목록에 2026-02-11 설치위치를 장비 ID로 연결했다. 최신 표에 좌표가 없는 5대는 2023-04-04 자료의 같은 ID에서 위도와 경도를 가져왔다. 02번 3단계에서 보관된 공식 CSV·엑셀 네 파일을 읽고 분석용 CSV와 대조한다. 10단계에서는 카메라 좌표로 시설 수를 다시 세어 지점별·사고별 CSV를 검산한다. [서울시설공단 운영목록](https://www.data.go.kr/data/15144351/fileData.do) · [연도별 설치위치](https://data.seoul.go.kr/dataList/OA-15273/L/1/datasetView.do)
