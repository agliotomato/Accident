# 데이터 전처리

2025년 기준 서울 사고누적지점 327곳의 관찰 기간을 2023~2025년으로 통일했다. 기존 합본에서 이 기간의 행을 골라 2025년 기준 원본과 대조했다. 전체 열의 값과 각 행의 출현 횟수가 일치해 원본을 분석용 자료의 기준으로 삼았다. 사고 유형과 결측값을 그대로 유지했다. [분석용 CSV](../data/processed/사고_분석용.csv)

2023년 1,539건, 2024년 1,462건, 2025년 1,563건으로 총 4,564행이다. 16자리 사고번호를 문자열로 확인한 결과 누락과 중복은 각각 0행이다. 이전 합본의 중복 초과 102행은 모두 분석에서 제외된 2022년 발생분에 속한다.

지점별 비중은 `지점ID + 사고번호`, 서울 전체 사고누적지점의 비중은 `사고번호` 기준으로 집계한다. 시간대·기상별 비중은 분모에도 같은 조건을 적용한다.

분석용 CSV에는 지점 중심 좌표, 발생 시점, 사고등급과 사상자 수, 당사자 및 차량 정보, 사고 유형과 도로·기상 관련 항목 등 26개 열을 사용한다. 시각은 두 자리로 저장하며, 사고번호와 지점ID 검증은 원본에서 수행한다.

[전처리 노트북과 실행 결과](../notebooks/01_prepare_crash_data.ipynb)
